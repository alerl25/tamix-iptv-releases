# Tamix IPTV

Instaladores de Tamix IPTV. Aquí solo se publican las versiones; la aplicación las busca sola y avisa cuando hay una nueva.

- **Windows (x64):** el `.exe` de la última versión.
- **Android, Android TV y Fire TV:** el `.apk` de la última versión.

Descargas: [última versión](https://github.com/alerl25/tamix-iptv-releases/releases/latest).
